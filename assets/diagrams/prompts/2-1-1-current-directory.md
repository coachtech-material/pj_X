```
教材の概念図（インフォグラフィック）を作成してください。

【内容】
- テーマ: コマンドラインの「現在地（カレントディレクトリ）」。入れ子のフォルダを、街区の建物・部屋の俯瞰地図に見立てて描く
- 中央に、いま立っている1つの部屋（フォルダ）を強調し、その中に人物キャラクター1体（ノートパソコンを操作する＝Claude Code を動かす人）を配置。その部屋の真上に「現在地」と書かれた大きなピン（位置マーカー）を立てる
- その部屋に3つの道具を擬物化して添える: (1)「pwd」と書かれた“あなたはここ”の案内看板、(2)「ls」と書かれた、部屋の中の箱や書類が見える窓、(3)「cd」と書かれた、隣の部屋へ通じる扉
- 周囲に別のフォルダの部屋を2〜3個、少し小さく淡く配置し、入れ子（階層）になっていることを示す
- 強調する部屋・ピン・道具ラベルにアクセントカラーを使い、周囲の部屋は淡いグレーの線画にする

【スタイル】
- フラットなインフォグラフィック／ベクター風を基調に、アイソメトリック（斜め上視点）で立体感を出す（建物・部屋・看板・扉に厚みを持たせる）
- 影はオブジェクト真下の単色フラット影のみ。ぼかし影・グラデーションは使わない
- 背景は #FFFFFF の単色。テクスチャ・しみ・もや・かすれを描かない
- 青（#3B82F6）とオレンジ（#F97316）のアクセントカラー、クリーンな線画、ラベルは日本語
- ラベルは「現在地」「pwd」「ls」「cd」のみ。タイトルや無関係な英単語など、指定外の文字は入れない
- 16:9 横長レイアウト
```
