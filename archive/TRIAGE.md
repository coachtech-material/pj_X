# 旧学習項目トリアージ（docs/04 → 本カリキュラム）

旧 pjX の学習項目（docs/04_学習項目.md、全110項目＋MVP対象外13項目）を、本カリキュラムのスコープで仕分けた対応表。OUTLINE.md の漏れ点検の基盤とする。

**判定の凡例**:

| 判定 | 意味 |
|---|---|
| **継承** | 内容をほぼそのまま教える |
| **変換** | 非エンジニア・業務委任の文脈に作り替えて教える |
| **題材化** | 知識としては教えず、演習題材（題材ライブラリ）として登場させる |
| **吸収** | 独立 Section にせず、他項目・他 Section の一部として扱う |
| **削除** | スコープ外（理由を記載） |

**配置先**は Part-Chapter（例: P2-2 ＝ Part 2 の Chapter 2）。配置先が前提とする Part 構成は旧 5 Part 案（入門＋思考＋仕様化＋実行＋仕組み化）の仮置きで、Part 構成の確定（ISSUES.md No.13）後に振り直す。Web アプリケーション関連の削除・吸収判定は見直し予定（ISSUES.md No.12）。
