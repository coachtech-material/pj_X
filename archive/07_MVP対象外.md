# pjX｜MVP対象外項目

MVPから除外した項目をここに保管する。
将来MVPに含め直す議論をする際は、このファイルから [04_学習項目.md](04_学習項目.md)／[05_学習項目詳細.md](05_学習項目詳細.md)（達成度は [03_達成度.md](03_達成度.md)）に戻す。
番号（No.111〜123）は、採用項目（No.1〜110）に続く連番として割り当てている。

## 除外の経緯

1. **AI開発（高度な製品化系）＝ No.111〜114** — キックオフのホワイトボードで「＋（プラスアルファ）」と整理されたため除外
2. **UIUX** — 同じく「＋」判定だが、現行の学習項目一覧に該当項目なし。「デザインのしくみ」（No.122）はホワイトボード上でUIUXとは別に挙がっていた「デザインコンポーネント」に対応する項目と判断していったんMVPに残したが、学習量の見直しで除外した（経緯5）
3. **ジャンル「AI活用・仕事術」＝ No.115〜117（＋達成度 No.40〜41）** — コラム的な位置づけのため除外
4. **工数見積（No.118）・投資の感覚（No.119、＋達成度 No.42）** — 工数見積・投資的な考え方（戦略コンサル寄りの内容）は育成の主対象から外す方針のため除外
5. **L3項目とデザインのしくみ＝ No.120〜123（＋達成度 No.43〜45）** — 卒業ゴール（L1＝現場に出せる）の2段階上にあたるL3項目（セキュリティ設計・実装／大規模システムの読解・改善／非機能要件）と、L1動線に乗らない「デザインのしくみ」を、学習量の見直しで除外

## 除外項目の詳細（学び方）

### No.111｜LLMアプリ開発（L3）

- **学習目標**: プロンプト設計＋評価＋ガードレール込みでLLM機能を製品に実装できる
- **学習ステップ**: ①機能設計 → ②プロンプト設計 → ③評価/ガードレール → ④実装 → ⑤運用
- **教材（読む／見る）**: LLMアプリ開発の解説
- **演習（やってみる・問題数）**: LLMを使う小機能を評価とガードレール込みで1本実装
- **備考**: 【応用】製品化／ベイカレント級 ／ 【前提・難度】API/プロンプト/評価/ガードレール一式。製品水準で重い

### No.112｜RAG（検索拡張生成）の実装（L3）

- **学習目標**: 自前データを検索してLLMに渡すRAGを実装できる
- **学習ステップ**: ①RAGの仕組み → ②データの取り込み/分割 → ③検索 → ④LLMに渡して回答
- **教材（読む／見る）**: RAGの解説、実装例
- **演習（やってみる・問題数）**: 小さなデータでRAGを1本実装
- **備考**: 【応用】製品化／ベイカレント級 ／ 【前提】API連携＋データ処理＋ベクトル検索の理解

### No.113｜ツール使用（function calling）の組み込み（L3）

- **学習目標**: function callingでLLMに外部操作をさせる機能を組み込める
- **学習ステップ**: ①ツール定義 → ②呼び出しの設計 → ③結果の扱い → ④安全に組み込む
- **教材（読む／見る）**: function calling/ツール使用の解説
- **演習（やってみる・問題数）**: ツールを1つ定義しLLMから呼ぶ機能を実装
- **備考**: 【応用】製品化／ベイカレント級 ／ 【前提】API連携＋ツール設計

### No.114｜AI機能の運用（監視・ログ・改善）（L3）

- **学習目標**: 本番のAI機能を監視・ログ・評価で改善し続けられる
- **学習ステップ**: ①ログ/監視を設計 → ②品質を継続評価 → ③問題を検知 → ④改善を回す
- **教材（読む／見る）**: AI機能の運用/監視の解説
- **演習（やってみる・問題数）**: あるAI機能のログ/監視/評価の運用を設計
- **備考**: 【応用】製品化／ベイカレント級 ／ 【前提】本番運用・監視の経験

### No.115｜音声入力（L1）

- **学習目標**: 声で作業を速める
- **学習ステップ**: ①音声入力ツールを使う → ②口述で文章/指示を出す
- **教材（読む／見る）**: 音声入力ツールの使い方
- **演習（やってみる・問題数）**: 口述で議事録/指示を作る

### No.116｜長い文章を読む力（L1）

- **学習目標**: 長文を速く正確に読む
- **学習ステップ**: ①拾い読み/論点抽出 → ②長文で練習
- **教材（読む／見る）**: 速読/論点抽出の解説、長いマークダウン
- **演習（やってみる・問題数）**: AIの長文出力から要点・誤りを抜き出す

### No.117｜画面・作業環境（L1）

- **学習目標**: 作業環境を整える
- **学習ステップ**: ①マルチディスプレイ/ショートカット等 → ②自分の環境を整える
- **教材（読む／見る）**: 作業効率化の解説
- **演習（やってみる・問題数）**: 自分の作業環境を見直して改善する

### No.118｜工数見積（L2）

- **学習目標**: 規模を分解して見積もり、根拠を示せる
- **学習ステップ**: ①見積りの考え方(分解/類推/三点) → ②機能を分解 → ③各々を見積もる → ④バッファ/前提を明示 → ⑤実績と比べて補正
- **教材（読む／見る）**: 工数見積の解説、見積り表の例
- **演習（やってみる・問題数）**: 機能を分解して見積もる2案件／前提と根拠を添える
- **備考**: 案件条件に応じた開発手法の選択と開発計画はNo.42で必須として扱う。詳細な工数見積はMVP対象外

### No.119｜投資の感覚（L2）

- **学習目標**: 費用対効果/ROIで施策を語り、経営層と話せる
- **学習ステップ**: ①ROI/費用対効果の考え方 → ②コスト/効果の見積り → ③投資判断の基準 → ④ROIで提案
- **教材（読む／見る）**: ROI/費用対効果の解説、投資判断の例
- **演習（やってみる・問題数）**: 施策のコストと効果を見積もりROIで提案文を2本
- **備考**: 投資的な考え方（戦略コンサル寄り）のためMVP対象外

### No.120｜セキュリティ設計・実装（L3）

- **学習目標**: 脅威モデリングで脅威を洗い出し、対策を設計・実装できる
- **学習ステップ**: ①脅威モデリング → ②対策の設計 → ③実装(認証/入力検証/暗号化等)
- **教材（読む／見る）**: セキュア設計の解説
- **演習（やってみる・問題数）**: ある機能の脅威を洗い出し対策を実装1題
- **備考**: 【追加】ベイカレント級 ／ 卒業ゴール（L1）の2段階上のため除外

### No.121｜大規模・複雑なシステムの読解・改善（L3）

- **学習目標**: 大規模/複雑なコードを読み解き設計上の問題を見つけ改善提案できる
- **学習ステップ**: ①大規模コードの読み方 → ②問題箇所の特定 → ③改善提案/リファクタ案
- **教材（読む／見る）**: リファクタリング/設計改善の解説
- **演習（やってみる・問題数）**: 複雑なコードを読み改善案を提案1〜2題
- **備考**: 【追加】ベイカレント級 ／ 卒業ゴール（L1）の2段階上のため除外

### No.122｜デザインのしくみ（L2）

- **学習目標**: デザインシステム/共通部品の考え方を理解し部品を扱える
- **学習ステップ**: ①デザインシステムの考え方 → ②既存のしくみ(部品/トークン)を読む → ③共通部品を作る
- **教材（読む／見る）**: デザインシステム入門
- **演習（やってみる・問題数）**: 共通部品(ボタン/入力欄等)の一覧を作る／既存UIを部品化1題
- **備考**: L1動線に乗らないため学習量の見直しで除外

### No.123｜非機能要件（性能・安全・可用性）（L3）

- **学習目標**: 性能/可用性/安全/拡張性を要件として洗い出し設計に反映できる
- **学習ステップ**: ①非機能要件の種類 → ②要件化の例 → ③あるシステムで洗い出す
- **教材（読む／見る）**: 非機能要件の解説
- **演習（やってみる・問題数）**: あるシステムの非機能要件を洗い出し設計反映を書く1題
- **備考**: 【追加】ベイカレント級 ／ 【前提・難度】システム設計の経験。卒業ゴール（L1）の2段階上のため除外
