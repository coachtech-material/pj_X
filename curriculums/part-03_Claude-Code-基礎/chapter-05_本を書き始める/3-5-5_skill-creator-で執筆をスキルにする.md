# 3-5-5 skill-creator で執筆をスキルにする

!!! note "前提知識"
    このセクションは 3-5-4「プロンプトと検証ゲートで第1章を書く」、3-3-2「Skills で手順を再利用する」、3-4-4「プラグインで既製の機能を導入する」の内容を前提としています。

!!! note "このハンズオンで使う機能"
    公式プラグイン skill-creator（Part3 で学んだプラグイン導入で入れます）と、Skills（Part3 で学習）を使います。一度踏んだ執筆手順を、呼び出すだけで再現できるスキルに落とし込みます。

## このセクションで学ぶこと

- 公式の skill-creator を導入する
- 第1章で踏んだ手順を、執筆スキルとして `my-book/.claude/skills/` に作る
- スキルを呼び出して、次の章を書いてみる
- 「呼べば章が書ける」状態と、まだ「仕組み」にはもう一歩（仕様の固定・資産化・2冊目展開は次の Part）であることを理解する

一度の作業を「呼び出せる形」に残す、再現の第一歩を体験します。

---

## 導入: 同じ手順を毎回打つのは面倒

第1章は、構成を立て、調べて書き、検証ゲートで仕上げる、という一連の手順で書きました。第2章、第3章でも同じ段取りを踏みます。毎回この手順を思い出して指示するのは面倒ですし、抜けも出ます。

そこで、この手順そのものをスキルにします。スキルにしておけば、次からは呼び出すだけで、同じ段取りで章を書けます。手で素朴に作ることもできますが（Part3 で体験済み）、ここでは公式の skill-creator に、いまの手順を読み取ってスキルへ落とし込んでもらいます。

---

## スキル化の前の確認

- [ ] 第1章を、前のセクション（3-5-4）の一連の手順で書き終えている
- [ ] 自分が踏んだ手順を、言葉でざっと説明できる
- [ ] `my-book` フォルダで `claude` を起動できる

---

## 実践: 執筆手順を skill-creator でスキルにする

### Step 1: skill-creator を導入する

skill-creator は公式マーケットプレイスのプラグインです。次の順に導入します（2026年6月時点）。

```text
/plugin marketplace add anthropics/claude-plugins-official
```

```text
/plugin install skill-creator@claude-plugins-official
```

導入したら、いまのセッションで使えるように読み込み直します。

```text
/reload-plugins
```

!!! warning "注意"
    `/plugin install` で「マーケットプレイスが見つからない」と言われたら、先に `/plugin marketplace add anthropics/claude-plugins-official` を実行してから入れ直します。コマンド名や手順はバージョンで変わることがあるので、うまくいかないときは公式ドキュメントの最新手順を確認してください。

### Step 2: いまの手順をスキルにしてもらう

導入した skill-creator は、`/skill-creator` で呼び出せます（スキルは「〜を作って」と頼んでも description から自動で起動します。3-3-2）。コマンドのうしろに、続けてどんなスキルにしたいかを書いて頼みます（スキルには `/スキル名 指示` の形で引数として指示を渡せます）。

```text
/skill-creator 本セッションで第1章を書いた一連の手順を読み取って、呼び出すだけで章を書ける執筆スキルにしてください。スキルは my-book の .claude/skills/ に作ってください。
```

skill-creator は、手順を読み取って `SKILL.md`（スキルの名前・説明・手順）を作ります。どんな名前・説明にするか、何を手順として書くかを提案してくるので、内容を確認して整えます。説明（description）は、Claude がいつこのスキルを使うかの判断材料になるので、「章を書くときに使う」と分かる書き方にします。

### Step 3: 別セッションにして、スキルを呼んで次の章を書く

スキルは `.claude/skills/` にファイルとして保存されました。CLAUDE.md や rules と同じで、新しいセッションでも自動で読み込まれて呼び出せます。ここまでの会話（第1章の執筆やスキル作成）でコンテキストが膨らんでいるので、ここで `exit` して起動し直すか `/clear` で会話を空にし、すっきりした状態で次の章に入りましょう（3-5-3 で見たセッションの切り替えです）。

新しいセッションで、できたスキルを呼び出して第2章を書いてみます。スキル名を `/` で呼ぶか、「次の章を書いて」と頼めば、Claude が同じ段取りで進めます。

```text
/（作ったスキル名） OUTLINE.md の第2章
```

毎回手順を指示しなくても、第1章のときと同じ段取りが再現されれば成功です。会話の記憶がリセットされた新しいセッションでもスキルが呼べることが、手順を「ファイルに資産として残せた」ことの証でもあります。気に入ったら、同じ要領で数章を書き進めてみてください。

### Step 4: できたことと、次の一歩を確かめる

スキルを呼べば、同じ段取りで次の章も書けます。これを繰り返せば最後まで書き進められますし、各章を検証ゲートとレビューで仕上げれば品質も保てます。一度の作業を「呼び出せる形」に残せた、これが再現の第一歩です。

一方で、いまの状態は、その場で作った手順（スキル）を呼んでいる段階です。本全体の設計（誰に・何を・どの順で・各章の狙い）は、まだ CLAUDE.md や OUTLINE.md に素朴に置いてあるだけで、「正」として固めた仕様にはなっていません。そのため、同じ品質で2冊目を量産したり、他の人に引き継いだりする「仕組み」には、もう一歩あります。手順・前提・仕様・運用をまとめてハーネスとして固め、資産にするのが、次の Part のテーマです。

## まとめ

- 一度踏んだ執筆手順は、skill-creator でスキルにできる。次からは呼び出すだけで同じ段取りが再現される
- スキルの説明（description）は、Claude がいつ使うかの判断材料。用途が分かるように書く
- スキルは1章の再現に効く。繰り返せば書き進められるが、仕様を「正」として固め、資産として再利用できる「仕組み」にするのは次の Part
