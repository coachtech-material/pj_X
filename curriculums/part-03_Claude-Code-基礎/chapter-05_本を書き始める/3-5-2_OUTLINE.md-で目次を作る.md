# 3-5-2 OUTLINE.md で目次を作る

!!! note "前提知識"
    このセクションは 3-5-1「CLAUDE.md で本の前提を用意する」と 1-3-4「構造化とアウトカムから決める完成条件」の内容を前提としています。

!!! note "このハンズオンで使う機能"
    本の目次ファイル `OUTLINE.md` を作ります。Part1 で学んだ構造化（漏れなくダブりなく＝MECE）を実践し、前のセクションで用意した CLAUDE.md の前提を踏まえて、本全体を章に分けます。

## このセクションで学ぶこと

- 本全体の章立て（目次）を `my-book/OUTLINE.md` にまとめる
- 章を漏れなくダブりなく（MECE）分け、各章に参考にする一次情報（出典）を添える
- この目次をもとに、第1章を「本の中の1章」として書けるようにする

前提（CLAUDE.md）の次は、本全体の目次を作ります。

---

## 導入: 第1章の前に、本全体の地図がいる

いきなり第1章から書き始めると、後半で「この話はもっと前に必要だった」「同じ説明を2つの章でしている」といったことが起きます。本のように大きな成果物では、先に全体を見渡す地図、つまり目次が要ります。

目次があると、第1章を「いきなり書く1本」ではなく「全体の中の1章」として書けます。前後の章との重複や抜けを避けられ、各章の役割がはっきりします。これは、Part1 で学んだ構造化（大きな対象を漏れなくダブりなく小さく分ける）を、本に当てはめる作業です。

## 実践: 目次を OUTLINE.md にまとめる

### Step 1: CLAUDE.md を踏まえて目次案を出させる

`my-book` で Claude Code を起動し、目次の案を出させます。CLAUDE.md の前提（とくに想定読者と狙い）を踏まえるよう頼むのがコツです。

```text
CLAUDE.md の想定読者と狙いを踏まえて、この入門書の目次案を OUTLINE.md にまとめてください。
各章に、次の2つを一行ずつ添えてください。
- その章で読者ができるようになること
- その章で参考にする一次情報（公式情報・書籍・統計など、信頼できる出典の名前や URL）
```

起動時に CLAUDE.md が読み込まれているので、前提に沿った目次案が返ってきます。最初の丸投げのときとは違い、ここではすでに前提が効いています。各章に参考にする一次情報も書いておくと、あとで章を書くとき（3-5-4）に、何を調べて裏を取ればよいかの当たりがつき、事実確認が速く正確になります。

### Step 2: 漏れとダブりを直す（MECE）

返ってきた目次を、自分の狙いと照らして点検します。次の観点で、気づいたら具体的に伝えて直させます。

- **漏れ**: 想定読者がつまずくのに、扱っていない話はないか
- **ダブり**: 同じ内容が複数の章にまたがっていないか
- **順序**: 前の章が次の章の前提になる、自然な並びか

例:「『○○』の章と『△△』の章で内容が重なっています。1つにまとめて、順番を入れ替えてください。」

### Step 3: OUTLINE.md として確定する

納得できる形になったら、`OUTLINE.md` として確定します。これが本全体の目次になり、以降の章はこれに沿って書きます。章が多ければ、章の中をさらに見出しで分けてもかまいません。

## まとめ

- 大きな本は、第1章を書く前に全体の目次を作る
- 目次は CLAUDE.md の前提を踏まえて作り、漏れなくダブりなく（MECE）整える。各章に参考にする一次情報（出典）も添えておく
