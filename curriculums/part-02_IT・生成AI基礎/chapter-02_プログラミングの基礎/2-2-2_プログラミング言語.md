# 2-2-2 プログラミング言語

!!! note "前提知識"
    このセクションは 2-2-1「プログラムの基本概念」の内容を前提としています。

## このセクションで学ぶこと

- プログラミング言語が複数あり、用途によって使い分けられること
- 主な言語それぞれの得意分野（JavaScript／TypeScript、Python、Java、PHP／Ruby、Go など）
- 値の種類を表す「型」があり、型エラーは AI が直す対象として読めればよいこと

プログラミング言語とは何かを押さえ、代表的な言語の使い分け、本研修で AI が主に書く言語、そして「型」の考え方までを見ていきます。

!!! note "補足"
    このセクションの本文に出てくる言語名やコードは、読んで違いをつかむための例です。言語の文法を覚える必要はありません。実際にコードを書く（AI に書かせる）のは、Part3 以降のハンズオンと Part6 のアプリ開発です。

---

## 導入: AI が「TypeScript で書きます」と言うとき

Claude Code に開発を任せると、「この部分は TypeScript で書きます」「データ処理なので Python を使います」のように、言語の名前が出てくることがあります。言語がいくつもあり、それぞれ何が得意なのかを大づかみに知っておくと、AI の判断が妥当か見当がつき、必要なら「この言語で」と方向を指定できます。何も知らないと、その判断をまるごと預けるしかなくなります。

---

## プログラミング言語とは

2-2-1 で見たプログラム（手順の指示）は、コンピュータに伝わる言葉で書く必要があります。その言葉が **プログラミング言語** です。

コンピュータが最終的に理解するのは 0 と 1 だけで表された言葉（機械語）ですが、人がそれを直接書くのは現実的ではありません。そこで、人にとって読み書きしやすい言葉でプログラムを書き、それをコンピュータ向けに変換して動かします。この「人が書くための言葉」がプログラミング言語で、目的や歴史の違いから何種類も生まれてきました。

自然言語に日本語・英語・フランス語があるように、プログラミング言語にも数多くの種類があり、それぞれ得意分野が違います。

## 用途で使い分ける主な言語

代表的な言語と、その得意分野を大づかみに挙げます。すべてを覚える必要はありません。「用途で使い分けるものなのだ」とつかめれば十分です。

| 言語 | 得意分野 |
|---|---|
| JavaScript／TypeScript | Web サイト・Web アプリ（画面も処理も）、業務の自動化 |
| Python | データ分析、AI・機械学習、自動化 |
| Java | 大規模な業務システム、Android アプリ |
| PHP／Ruby | Web アプリ・Web サービスの構築 |
| Go | 高速な処理が求められるサーバやツール |

同じ「Web アプリを作る」でも複数の言語が候補になり、どれを選ぶかは、性能・開発のしやすさ・AI との相性・周辺の道具の充実度などで決まります（本研修の Part6 で何を選び、なぜそうするかは、その都度 Claude と相談しながら決めます）。

## 本研修で AI が書く言語: TypeScript／JavaScript

本研修で AI に書かせる対象は、主に **TypeScript／JavaScript** です。

**JavaScript** は、もともと Web ブラウザの中で画面を動かすために生まれた言語で、いまでは画面側（フロント）からサーバ側の処理まで幅広く使われます。Web で最も広く使われている言語の一つで、AI が正しいコードを書くための情報も豊富です。

**TypeScript** は、その JavaScript に「型」（次に説明します）の仕組みを足して、間違いを早く見つけやすくした言語です。書いたものは最終的に JavaScript として動きます。

Part6 で作るアプリも、この TypeScript／JavaScript を中心に Claude Code が書いていきます。広く使われていて AI が正確に書きやすいことが、学習者がコードを書かずに最後まで作り切るうえで効いてきます。

## 値の種類を表す「型」

プログラムが扱う値には、種類があります。たとえば「100」は数値、「牛乳」は文字、「真か偽か」は真偽値です。この値の種類を **型** と呼びます。

型を意識する言語（TypeScript など）では、「ここには数値が入るはず」とあらかじめ決めておけます。すると、うっかり文字を入れようとしたときに、動かす前から「型が合いません」と教えてくれます。これを **型エラー** と呼びます。

型エラーは、不具合を早い段階で見つけてくれる安全装置のようなものです。本研修では、型を自分で設計したり型エラーを自分で直したりはしません。AI が書き、AI が直します。私たちは「型が合わないと言っている＝値の種類が想定と違う」と読めれば十分です。

!!! note "補足"
    型エラーのようなメッセージが画面に出ても、慌てる必要はありません。多くは AI に「このエラーを直して」と伝えれば対処してくれます。エラーが出たときの伝え方・直し方は、Part3（3-1-6）と Part6 で扱います。

---

## まとめ

- プログラミング言語は、プログラム（手順）を書くための、人が読み書きしやすい言葉。用途や歴史の違いから何種類もある
- JavaScript／TypeScript は Web、Python はデータ分析・AI、Java は大規模業務システム、というように得意分野で使い分ける
- 本研修で AI が書くのは主に TypeScript／JavaScript。広く使われ、AI が正確に書きやすい
- 値の種類を表すのが「型」で、種類が想定と違うと型エラーになる。型エラーは AI が直す対象で、人は「値の種類が合っていない」と読めればよい
