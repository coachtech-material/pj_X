# 1-2-2 VS Code を用意してプロジェクトを開く

!!! note "前提知識"
    このセクションは 1-2-1「Claude Code のインストールと認証」の内容を前提としています。

## このセクションで学ぶこと

- コードエディタ VS Code を、自分の OS（macOS／Windows）に合わせてインストールする
- `code .` でフォルダを VS Code で開き、その統合ターミナルで Claude Code を動かす
- Claude Code 拡張を入れて、AI が直したファイルの差分を見やすくする
- 統合ターミナルを横に分割して、複数の作業を並べられることを知る（実際に使うのは後の Part）

Claude Code が作る・直すファイルを目で追えるように、フォルダを開く「器」として VS Code を用意し、その中のターミナルで Claude Code を動かせる状態を作ります。

---

## 導入: ターミナルだけでは、AI の仕事が追いにくい

1-2-1 で Claude Code を起動できるようになりました。ただ、ターミナルの画面だけで作業を進めると、困ることがあります。Claude Code が複数のファイルを作ったり直したりしたとき、どのファイルがどこにあって、いま中身がどうなっているのかが、文字の流れの中では掴みにくいのです。

そこで、フォルダの中身を一覧で見られて、ファイルを開いて中身を確かめられる道具を用意します。それがコードエディタ VS Code（Visual Studio Code）です。本研修では、Claude Code はこれまでどおりコマンドで動かしつつ、その作業の様子を VS Code で目で追えるようにします。

!!! quote "現場での考え方"
    自分が最初にターミナルだけで Claude Code を使っていたとき、AI が3つのファイルを同時に直したことがありました。何がどう変わったのかを追えず、結局どれが本筋の変更か分からなくなりました。フォルダごと VS Code で開くようにしてからは、左の一覧で変わったファイルがすぐ分かり、中身もその場で読めて、確認が速くなりました。

---

## VS Code は何をする道具か

VS Code は、広く使われている無料のコードエディタです。本来はプログラマーがコードを書くための道具ですが、本研修ではコードを書くためでなく、次の3つのために使います。

- **ファイルの一覧を見る**: フォルダを開くと、左側にその中のファイル・フォルダがツリー（階層の一覧）で表示され、プロジェクト全体を見渡せます。
- **中身と差分を見る**: ファイルをクリックすると中身が開きます。Claude Code が変更を提案したとき、その前後の差分も見やすく表示できます。
- **ターミナルを内蔵している**: VS Code の中でターミナルを開けます（統合ターミナルと呼びます）。ここで `claude` を動かせば、編集とファイル一覧が同じ画面にそろいます。

VS Code は無料で、macOS・Windows のどちらでも同じように使えます。

## 本研修での VS Code の使い方

ここで、役割をはっきりさせておきます。本研修は、これまでどおり Claude Code をコマンド（`claude`）で動かすことを基本にします。VS Code は、Claude Code を動かす場所であり、ファイルの中身を見る画面でもあります。具体的には、プロジェクトのフォルダを VS Code で開き、その中の統合ターミナルで `claude` を打つだけです。統合ターミナルは、1-2-1 で使ったターミナルと同じもので、VS Code の中で開くだけの違いです。だから、これまで覚えた操作はそのまま通用します。

もう一つ、名前について先に整理しておきます。このあと VS Code に「Claude Code」という名前の拡張機能を入れます。ただし、これは 1-2-1 でインストールした、ターミナルで動く Claude Code とは別のものです。同じ「Claude Code」でも、大きく2つの形があります。

- **ターミナルで動かす本体（CLI）**: 1-2-1 で入れたもの。ターミナルで `claude` と打って起動し、文字でやり取りします。本研修はこれを一貫して基本にします。
- **VS Code 拡張（パネル）**: これから入れるもの。VS Code の中に専用のパネル（チャット欄）を表示し、そこで Claude Code を動かす形です。

動かす場所と見た目が違う別物で、コマンド（CLI）で使える機能のすべてがパネルで使えるわけではありません。そのため本研修は、どの機能も使える CLI（ターミナルの `claude`）を基本にし、拡張のパネルは使いません。

では、なぜ拡張を入れるのか。それは、ターミナルの Claude Code がファイルを直したときに、その変更前後の差分を、VS Code の見やすい画面（差分ビューア）で確認できるようにするためです。拡張を入れておくと、統合ターミナルの `claude` と VS Code が自動で連携し、この差分表示が働きます。

## 実践: VS Code を用意してプロジェクトを開く

ここから手を動かします。お使いの OS のタブを選んで進めてください。手順・画面はバージョンで少しずつ変わります（以下は 2026年6月時点）。

### Step 1: VS Code をインストールする

=== "macOS"
    1. ブラウザで [Visual Studio Code の公式サイト](https://code.visualstudio.com) を開き、ダウンロードボタンから macOS 版を入手します（Mac の種類は自動で判別されます）。
    2. ダウンロードされた `.zip`（または `.dmg`）を開くと、「Visual Studio Code」のアイコンが出てきます。
    3. そのアイコンを「アプリケーション」フォルダにドラッグして入れます。
    4. 「アプリケーション」フォルダの中の「Visual Studio Code」をダブルクリックして起動します。初回は「開いてよいか」の確認が出ることがあるので、「開く」を選びます。

=== "Windows"
    1. ブラウザで [Visual Studio Code の公式サイト](https://code.visualstudio.com) を開き、ダウンロードボタンから Windows 版（User Installer）を入手します。
    2. ダウンロードされた `VSCodeUserSetup-……​.exe` をダブルクリックして実行します。
    3. 案内に従って進めます。途中の追加タスクの選択で、**「PATH への追加」** は既定でチェックが入っているので、そのまま進めます（これが、あとで `code` コマンドを使うために必要です）。
    4. インストールが終わったら、VS Code を起動します。

### Step 2: `code` コマンドを使えるようにする

ターミナルから `code` と打つだけで VS Code が開くようにします。設定の仕方は OS で分かれます。

=== "macOS"
    1. VS Code を起動した状態で、`command`（⌘）+ `Shift` + `P` を押します。画面上部にコマンドパレット（コマンドを検索して実行する入力欄）が開きます。
    2. そこに `shell command` と入力すると、候補に **「Shell Command: Install 'code' command in PATH」** が出てきます。これを選んで Enter を押します。
    3. 「設定しました」という主旨の通知が出れば完了です。設定を反映するため、開いているターミナルがあれば一度閉じて開き直します。

=== "Windows"
    Step 1 のインストーラで「PATH への追加」が済んでいるので、追加の設定は不要です。設定を反映するため、開いている PowerShell があれば一度閉じて、1-2-1 と同じ手順で開き直してください（再起動で `code` コマンドが使えるようになります）。

設定できたか確かめます。ターミナル（macOS は Terminal.app、Windows は PowerShell）で次を打って Enter を押します。

```bash
code --version
```

`1.10x.x`（数字はバージョンで変わります）のような行が表示されれば、`code` コマンドが使える状態です。

!!! warning "よくあるエラー"
    設定の直後に `code` を打つと、コマンドが見つからないというメッセージが出ることがあります。文面は OS で異なり、macOS では次のように、Windows では `'code' は……認識されません` のように表示されます。

    ```text
    command not found: code
    ```

    **原因**: `code` コマンドの設定が、いま開いているターミナルにまだ反映されていません。

    **対処法**: ターミナル（Windows は PowerShell）をいったん閉じて開き直し、もう一度 `code --version` を試してください。多くの場合これで解決します。

### Step 3: フォルダを `code .` で開く

`code` コマンドが使えるようになったので、フォルダを VS Code で開いてみます。ターミナルで、いまいる場所（最初に開いたときは、多くがあなたのユーザーフォルダ＝ホーム）のまま、次を打って Enter を押します。

```bash
code .
```

VS Code のウィンドウが開き、左側にいまいるフォルダの中身がツリー（一覧）で表示されます。`code` の後ろの `.`（ドット）は「いまいるフォルダ」を指す書き方です（この `.` の意味は 2-1-2 で詳しく扱います。ここでは「`code .` で、いまいるフォルダを VS Code で開く」と覚えれば十分です）。別のフォルダを開きたいときは、ターミナルでそのフォルダへ移動してから `code .` を打つか、フォルダ名を付けて `code フォルダ名` と打ちます。

### Step 4: 統合ターミナルで Claude Code を起動する

VS Code の中にもターミナルがあります。VS Code の上部メニューから「ターミナル」→「新しいターミナル」を選ぶと、画面の下半分にターミナルが開きます（`` Control+` ``〔Windows〕／`` Command+` ``〔macOS〕のショートカットでも開けます。`` ` `` はキーボードの左上あたりにあるバッククォートです）。

この統合ターミナルは、1-2-1 で使ったターミナルと中身は同じで、VS Code の中で開くだけの違いです。いまは `code .` で開いたフォルダがそのまま作業場所になっています。ここに次を打って Enter を押し、Claude Code を起動します。

```bash
claude
```

1-2-1 でログインを済ませているので、すぐに入力画面（プロンプト）が表示されます。`/help` と打って Enter を押すとコマンド一覧が出て、正しく動いていることを確認できます。確認できたら、いったん `/exit` で終了しておきます（次のセクションであらためて使います）。

!!! note "補足"
    拡張（次の Step）を入れていなくても、VS Code の統合ターミナルで `claude` は問題なく動きます。1-2-1 でインストールした Claude Code 本体が、この統合ターミナルでもそのまま使われます。

### Step 5: 統合ターミナルを分割してみる（知っておくだけで十分）

統合ターミナルは、画面を分けて複数同時に開けます。いますぐ使う場面はありませんが、後の Part で「片側で開発中のアプリを動かしながら、もう片側で Claude Code に作業させる」（Part6）や、「複数の Claude Code を並べて別々の仕事を任せる」（3-4-2）といった使い方が出てきます。やり方をここで一度だけ確認しておきます（統合ターミナルの操作の解説は、この VS Code のセクションにまとめてあります。以降の Part はここを参照します）。

1. いま開いている統合ターミナルの上で、`command`（⌘）+ `\`（バックスラッシュ）〔macOS〕／`Ctrl` + `Shift` + `5`〔Windows〕を押します。ターミナルが左右2つのペイン（区画）に分かれます。ターミナルの上で右クリックして「分割（Split）」を選んでも同じです。
2. 左右のペインは、それぞれ別のターミナルとして使えます。マウスでクリックするか、ペイン移動のショートカット（`option`〔⌥〕+ `command`〔⌘〕+ `←`／`→`〔macOS〕、`Alt` + `←`／`→`〔Windows〕）で行き来します。
3. 確認できたら、使わない側のペインで `exit` と打って Enter を押すか、ペイン右上の `×` で閉じて、1つに戻しておきます。

分割（ペイン）ではなく、まったく別のターミナルをタブで増やしたいときは、ターミナルパネル右上の `+` を押すか、`Ctrl` + `Shift` + `` ` ``（バッククォート。macOS・Windows 共通）で新しいタブを開けます。いまは「こういうことができる」と知っておけば十分で、実際に並行作業として活かすのは Part6（開発サーバと Claude の並走）と 3-4-2（複数セッションの並列）です（2026年6月時点）。

### Step 6: Claude Code 拡張を入れる

最後に、Claude Code の VS Code 拡張を入れます。さきほど整理したとおり、これは 1-2-1 で入れたターミナルの Claude Code（CLI）とは別物です。入れる目的は、AI が直したファイルの変更前後の差分を、VS Code の見やすい画面（差分ビューア）で確認できるようにすることです。

1. VS Code の左端のアイコンの中から、拡張機能（四角が組み合わさったアイコン）を開きます（`command`〔⌘〕+ `Shift` + `X`〔macOS〕／`Ctrl` + `Shift` + `X`〔Windows〕でも開けます）。
2. 上部の検索欄に `Claude Code` と入力します。
3. 一覧の上の方に、発行元が **Anthropic** の「**Claude Code for VS Code**」が出てきます。これを選び、**「インストール」** を押します（似た名前の別の拡張もあるので、発行元が Anthropic であることを確かめてから入れます）。

これで、差分が VS Code 上で見やすく表示されるようになります（拡張の利用には VS Code のバージョン 1.98.0 以上が必要です。2026年6月時点）。本研修での Claude Code の動かし方は、これまでどおり統合ターミナルで `claude` を打つやり方のままで、拡張のパネルは使いません。

!!! warning "注意"
    この拡張を入れても、ターミナルで `claude` が打てるようになるわけではありません。拡張はパネル用に内部で別の Claude Code を抱えており、ターミナルの `claude` には 1-2-1 のインストール（スタンドアロン版）が引き続き必要です。本研修はそれを 1-2-1 で済ませてあるので、追加の作業はありません。もし統合ターミナルで `claude` が見つからない場合は、ターミナルを開き直すか、1-2-1 の確認手順（`claude --version`）に戻ってください。

## まとめ

- VS Code は、フォルダの中身を一覧で見て、ファイルの中身や差分を確かめ、ターミナルも内蔵する無料のコードエディタ。本研修ではコードを書くためでなく、AI の作業を目で追う「器」として使う
- `code` コマンドを使えるようにすると、ターミナルで `code .` と打つだけでフォルダを VS Code で開ける（macOS はコマンドパレットで設定、Windows はインストーラが既定で設定）
- Claude Code は、これまでどおりコマンドで動かす。VS Code の統合ターミナルで `claude` を打つだけで、編集とファイル一覧が同じ画面にそろう
- VS Code 拡張「Claude Code for VS Code」は、ターミナルの Claude Code（CLI）とは別物。本研修ではそのパネルは使わず、AI が直した差分を見やすく表示するために入れる
- 統合ターミナルは横に分割したりタブで複数開いたりできる。片側で開発サーバ、もう片側で Claude のように、後で並行作業に使う（操作・ショートカットの解説はこのセクションに集約）
