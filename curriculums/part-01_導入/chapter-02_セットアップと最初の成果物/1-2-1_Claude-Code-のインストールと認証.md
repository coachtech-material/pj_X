## 導入: 最初の関門は、環境づくり

新しい道具を使うとき、最初のつまずきは多くの場合「使い始める前の準備」で起きます。Claude Code も、いったん起動できる状態まで持っていければ、あとは会話するだけです。逆に、ここでつまずくと先に進めません。このセクションは、その準備を一つずつ確実に終わらせることに集中します。

!!! quote "現場での考え方"
    自分が最初に手こずったのは、Windows でインストールのコマンドを打ったのに「コマンドが認識されません」というエラーが出たことでした。原因は単純で、PowerShell 用のコマンドを、見た目のよく似た別の画面（コマンドプロンプト）に打ち込んでいたからです。どの画面で作業しているかを取り違えると、正しいコマンドでも動きません。最初は、いま自分がどの画面を開いているかを確かめる癖をつけると、つまずきが減ります。

## Claude Code を使うのに必要なもの

インストールに進む前に、次の3つを確認します。

**1. 契約プラン**

Claude Code を使うには、Claude の有料プランの契約が必要です。無料の Claude.ai プランには Claude Code の利用は含まれていません（2026年6月時点）。利用できるのは Pro・Max・Team・Enterprise などの有料プラン、または API 利用枠を持つ Console アカウントです。

本研修では、まず **Pro プラン** を推奨します。Part1 から Part5 までは Pro で支障なく進められます。まだ契約していない場合は、Claude の公式サイト（料金ページ）から Pro を契約してください。

!!! tip "ヒント"
    最後の Part6（アプリ開発実践）は、AI に任せる作業量が多く、消費が大きくなります。そのため Pro の一定時間あたりの利用枠を超えて、待ち時間が出ることがあります（利用枠の具体的な数値は変わりやすいため、契約時に最新の案内を確認してください）。Part6 をスムーズに進めたい場合は、その時点で上位の Max プランを検討できます。Part5 までは Pro のままで問題ありません。

**2. 対応している OS**

Claude Code は、macOS 13.0 以上、または Windows 10（1809 以上）以上で動きます。あわせて 4 GB 以上のメモリと、インターネット接続が必要です（2026年6月時点）。お使いのパソコンが macOS か Windows のどちらかであれば、まず問題ありません。

**3. 使うターミナル**

Claude Code は、文字でやり取りする画面（ターミナル）から起動します。本研修では、追加インストールが不要で標準で備わっているものを推奨し、それで統一して進めます。

- **macOS**: 標準の「ターミナル」（Terminal.app）
- **Windows**: 「PowerShell」

本研修は、この推奨ターミナルで統一して進めます。特にこだわりがなければ、そのまま使ってください。

!!! tip "ヒント"
    Claude Code は、特別な設定をしなくても、どのターミナルでも動きます。世の中には Terminal.app や PowerShell のほかにも、表示や操作性を工夫したターミナルが数多くあります（macOS で人気の iTerm2・Warp、Windows の Windows Terminal、どちらでも使える WezTerm・Ghostty など。使えるものは OS によって異なります）。ターミナルにこだわると作業のたびの気分も変わるので、気になる人は調べて、好みのものを試してみるのも面白いはずです。公式ドキュメントのターミナル設定の解説には、こうしたターミナルごとの細かな設定もまとまっています。本研修自体は、追加インストールが不要な Terminal.app／PowerShell で統一して進めるので、まずはこのまま読み進めて大丈夫です。

!!! note "補足"
    Claude Code は、ターミナルのほかに VS Code 拡張・デスクトップ版・Web 版でも使えます。ただし、どの環境でも考え方は共通です。本研修は、どの環境にも通用する土台として、ターミナルを基本に進めます。

## 実践: Claude Code をインストールして認証する

ここから実際に手を動かします。お使いの OS のタブを選んで進めてください。

### Step 1: ターミナルを開く

お使いの OS に合わせて、ターミナルのウィンドウを開きます。

=== "macOS"
    キーボードの `command`（⌘）キーを押しながら、スペースキーを押します。画面の中央あたりに検索ボックス（Spotlight 検索）が表示されます。そこに `terminal` と入力すると、候補の一番上に「ターミナル」が出てくるので、`return`（Enter）キーを押します。白または黒のウィンドウが開きます。

=== "Windows"
    キーボードの `Windows`（⊞。スペースキーの左どなりにある、窓のロゴのキー）を押しながら、`X` キーを押します。画面の左下にメニューが出るので、その中の「ターミナル」または「Windows PowerShell」をクリックします。`PS C:\Users\（あなたの名前）>` のような表示のウィンドウが開きます。行の先頭に `PS` が付いていれば PowerShell です。

ウィンドウの中で点滅している縦棒（カーソル）が、文字の入力位置です。ここにコマンドを打ち、最後に Enter キーを押して実行します。

### Step 2: インストールのコマンドを実行する

ターミナルに、次のコマンドを打って（コピー＆ペーストでも構いません）、Enter キーを押します。インストールが始まり、進み具合が文字で表示されます。完了まで少し待ちます。

=== "macOS"
    ```bash
    curl -fsSL https://claude.ai/install.sh | bash
    ```

=== "Windows"
    PowerShell に、次のコマンドを打って Enter を押します。

    ```powershell
    irm https://claude.ai/install.ps1 | iex
    ```

!!! warning "注意"
    Windows には、見た目のよく似た「PowerShell」と「コマンドプロンプト（CMD）」の2つがあります。上の `irm` から始まるコマンドは PowerShell 用です。行の先頭に `PS` が付いていれば PowerShell、付いていなければ CMD です。`'irm' is not recognized` のようなエラーが出たら CMD を開いている可能性が高いので、Step 1 の手順で PowerShell を開き直してください。

### Step 3: インストールできたか確認する

インストールが終わったら、結果を確実に反映させるため、いまのターミナルのウィンドウを一度閉じて、Step 1 の手順で新しく開き直します。そのうえで、次のコマンドを打って Enter を押します。

```bash
claude --version
```

`2.1.x`（数字はバージョンによって変わります）のようなバージョン番号が1行表示されれば、インストールは成功です。

!!! warning "よくあるエラー"
    開き直した直後でも、まれに「コマンドが見つからない」という意味のメッセージが表示されることがあります。文面は OS で異なり、macOS では次のように、Windows では `'claude' は…認識されません` のように表示されます。

    ```text
    command not found: claude
    ```

    **原因**: インストールした場所が、ターミナルがコマンドを探す範囲にまだ反映されていないことがあります。

    **対処法**: もう一度ターミナルを閉じて開き直し、再度 `claude --version` を試してください。それでも解決しない場合は、Claude Code に付属する点検コマンド `claude doctor` を実行すると、原因と対処の案内が表示されます。

### Step 4: Claude Code を起動してログインする

次のコマンドを打って Enter を押し、Claude Code を起動します。

```bash
claude
```

初回の起動では、ログインを求められます。画面の案内に従って、お使いの Claude アカウント（Pro など）でのログインを選び、Enter を押します。自動でブラウザが開くので、ログインして、表示される許可（認可）の画面に同意してください。済んだらターミナルに戻ります。認証情報は保存されるので、次回からはこの手順は不要です（あとからアカウントを切り替えたい、ログインし直したいときは、起動中の Claude Code の画面で `/login` と打てば、もう一度ログインの手順を始められます）。

### Step 5: 起動した画面を確認する

ログインが終わると、Claude Code の入力画面（プロンプト）が表示されます。画面の上部に、バージョン・いま使っているモデル・作業中のフォルダ（作業ディレクトリ）が表示されています。

ここで `/help` と打って Enter を押すと、使えるコマンドの一覧が表示されます。これが表示されれば、Claude Code は正しく動いています。一覧を確認したら、いまはまだ依頼はせず、`/exit` と打って Enter を押し、いったん終了しておきます（次のセクションであらためて起動します）。

## まとめ

- Claude Code を使うには有料プラン（本研修は Pro を推奨）が必要。無料の Claude.ai プランでは使えない
- 推奨ターミナルは macOS の標準ターミナル、Windows の PowerShell。どちらも追加インストール不要
- インストールは OS ごとのコマンド1行。`claude --version` で確認し、`claude` で起動してブラウザからログインすれば、使える状態になる
- うまくいかないときは、ターミナルを開き直す、`claude doctor` で点検する、画面（PowerShell か CMD か）を確かめる
