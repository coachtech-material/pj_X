# pjX｜達成度（到達レベル別）

## 到達レベルの目安

| レベル | 名称 | 説明 |
|---|---|---|
| L1 | 現場に出せる | 卒業時の目標。報酬をもらって案件に入り、上流の初動ができる。（目安：数ヶ月） |
| L2 | 中堅コンサル | 案件で信頼を得て単価を上げ、上流に深く関わり、自分で設計できる。（目安：実務で数年） |
| L3 | ベイカレント級 | 高度な設計・複雑な案件・PMまで。技術とコンサルの両面で高水準。（目安：さらにその先） |
