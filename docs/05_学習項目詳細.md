## ビジネス

### 日本語の基礎

#### No.1｜語彙（L1）

- **学習目標**: ビジネス頻出語・抽象/具体の言い換えができ、曖昧語を具体語に置き換えられる
- **学習ステップ**: ①頻出語・敬語/言い換えを学ぶ → ②抽象⇄具体の往復 → ③曖昧語(これ/やつ/いい感じ/ちゃんと等)を具体語に直す → ④類語の使い分け → ⑤自分の文章から曖昧語を狩る
- **教材（読む／見る）**: 言い換え・類語辞典、ビジネス頻出語リスト、曖昧語を含む悪文例集
- **演習（やってみる・問題数）**: 曖昧文の具体化10〜15文／類語の使い分け10問／過去メールから曖昧語を抽出し修正3通

#### No.2｜文法（L1）

- **学習目標**: 主述の対応・修飾の係り先・接続を正しく扱い、一文一義で書ける
- **学習ステップ**: ①主述のねじれ → ②修飾語の係り先・使いすぎ → ③接続詞の使い分け → ④一文一義 → ⑤意味段落 → ⑥悪文を添削して直す
- **教材（読む／見る）**: 日本語文法・悪文添削の解説書、ねじれ文/長文の悪例集、接続詞一覧
- **演習（やってみる・問題数）**: ねじれ文の修正15文／長文を一文一義に分解10題／接続詞の穴埋め10問

#### No.3｜文章構成（L1）

- **学習目標**: 結論先出し(PREP/SDS)で、論理の通った段落・文章を組める
- **学習ステップ**: ①結論先出しの意義 → ②PREP/SDSの型 → ③箇条書き→段落化 → ④根拠→主張の接続を点検 → ⑤だらだら文を再構成
- **教材（読む／見る）**: 文章構成(PREP/SDS)の解説、良い構成のサンプル
- **演習（やってみる・問題数）**: 箇条書きから結論先出しの段落を5本／だらだら文を再構成5題

#### No.4｜読解（L1）

- **学習目標**: 事実・主張・根拠を読み分け、書いていない前提や抜けを指摘し要約できる
- **学習ステップ**: ①事実/主張/根拠を線引き → ②主張と根拠の対応を点検 → ③前提・抜け・飛躍を指摘 → ④要点を要約
- **教材（読む／見る）**: 説明文・仕様/契約文、クリティカルリーディングの解説
- **演習（やってみる・問題数）**: 論点・前提・抜けの抽出5題／要点を3行要約5題

### 思考法

#### No.5｜論点思考（L1）

- **学習目標**: 与件から「解くべき問い」を立て、筋の良し悪しを判断できる
- **学習ステップ**: ①問いと作業の違い → ②良い論点の条件(解けて・効く) → ③与件から論点を立てる例 → ④自分で立てる → ⑤筋の良さを点検・修正
- **教材（読む／見る）**: 論点思考の解説、ケースの論点設定例
- **演習（やってみる・問題数）**: 状況文から論点を立てる5ケース／悪い論点を良い論点に直す5題

#### No.6｜仮説思考（L1）

- **学習目標**: 早めに仮説を立て、確かめる手順まで設計できる
- **学習ステップ**: ①仮説→検証の流れ → ②仮説の立て方(So what/Why) → ③検証手順の設計 → ④結果で仮説を更新
- **教材（読む／見る）**: 仮説思考の解説、検証設計の例
- **演習（やってみる・問題数）**: 課題ごとに仮説3つ＋検証方法を書く5題

#### No.7｜構造化（MECE）（L1）

- **学習目標**: MECEに分解しロジックツリーで整理でき、漏れ/ダブりを点検できる
- **学習ステップ**: ①MECEとは → ②切り口(時系列/対象/要素) → ③ロジックツリー → ④漏れ/ダブり点検 → ⑤分解を成果物に
- **教材（読む／見る）**: MECE/ロジックツリーの解説、良い分解例
- **演習（やってみる・問題数）**: テーマをMECE分解しツリー化5題／崩れた分解を直す5題

#### No.8｜事実と解釈を分ける（L1）

- **学習目標**: 文章中の事実/解釈/意見を仕分け、報告で混同しない
- **学習ステップ**: ①事実/解釈/意見の定義 → ②混在文を分類 → ③解釈に根拠を添える → ④自分の報告を仕分け
- **教材（読む／見る）**: 事実と意見の区別の解説、混在文章例
- **演習（やってみる・問題数）**: 各文をラベル付け10題／自分の報告文を仕分け・修正3通

#### No.9｜事実・数字で語る（L1）

- **学習目標**: 定性表現を定量化し、数字で主張を支えられる
- **学習ステップ**: ①定性→定量に直す → ②比較の基準(率/差/推移) → ③数字の見せ方 → ④主張に数字を添える
- **教材（読む／見る）**: 定量化・数字の使い方の解説
- **演習（やってみる・問題数）**: 定性表現を数字に置き換え10文／主張に根拠数字を添える5題

#### No.10｜フレームワーク運用（L1）

- **学習目標**: 目的に合う型(表/マトリクス/プロセス図)を選び、情報を成果物に整理できる
- **学習ステップ**: ①代表的な型を学ぶ → ②型の選び方(目的に合わせる) → ③情報を型に当てる → ④過剰な型当てを避ける
- **教材（読む／見る）**: 整理フレームの一覧と例、型に整理した成果物
- **演習（やってみる・問題数）**: 散らかった情報を適切な型で整理5題／型の選択理由を書く

### 対人コミュニケーション

#### No.11｜ヒアリング／傾聴（L1）

- **学習目標**: 傾聴と深掘りで、言葉の裏の本当の要望を引き出し記録できる
- **学習ステップ**: ①傾聴の姿勢 → ②オープン/深掘り質問 → ③Why/具体化で掘る → ④要約して確認 → ⑤記録に起こす
- **教材（読む／見る）**: ヒアリング/傾聴の解説、良いヒアリング記録のサンプル
- **演習（やってみる・問題数）**: 模擬ヒアリングを3ケース実施し、要望整理に書き起こす

#### No.12｜質問力（L1）

- **学習目標**: 状況に応じた質問を設計し、話を前に進められる
- **学習ステップ**: ①質問の種類(開/閉/深掘り) → ②良い/悪い質問の比較 → ③論点を進める質問を作る → ④誘導/詰問を避ける
- **教材（読む／見る）**: 質問技法の解説
- **演習（やってみる・問題数）**: 状況ごとに質問リスト(各5問)を3ケース作る

#### No.13｜信頼関係づくり（L1）

- **学習目標**: 早期に信頼を作り、本音を引き出せる関係に持っていける
- **学習ステップ**: ①信頼の要素(誠実/共感/有能/一貫) → ②初対面の入り方 → ③相手に合わせる → ④約束を守る運用
- **教材（読む／見る）**: 信頼構築・対人の解説、良い/悪い対応例
- **演習（やってみる・問題数）**: 初回面談の台本を作りロールプレイ3回

#### No.14｜関係者マネジメント（L2）

- **学習目標**: 関係者と意思決定者を把握し、合意までの段取りを設計できる
- **学習ステップ**: ①ステークホルダー分析(影響度/関心度) → ②関係者マップ → ③キーパーソン/抵抗勢力の見極め → ④合意の順序を設計 → ⑤根回しの段取り
- **教材（読む／見る）**: ステークホルダー分析の解説、関係者マップの例
- **演習（やってみる・問題数）**: ケースの関係者をマップ化し合意計画を作る3ケース

#### No.15｜ファシリテーション（L2）

- **学習目標**: アジェンダ設計と発散/収束で、会議を結論まで運べる
- **学習ステップ**: ①会議の目的/ゴール → ②アジェンダ設計 → ③発散(意見を出す) → ④収束(まとめる) → ⑤決定と宿題を残す
- **教材（読む／見る）**: ファシリテーションの解説、アジェンダ/議事のサンプル
- **演習（やってみる・問題数）**: アジェンダを作り模擬会議を進行、結論と議事録を出す2回

#### No.16｜期待値調整（L1）

- **学習目標**: できる/できない/前提を明示し、相手とすり合わせられる
- **学習ステップ**: ①期待値ギャップの原因 → ②前提の言語化 → ③代替案の出し方 → ④断り方/伝え方の型 → ⑤合意の確認
- **教材（読む／見る）**: 期待値調整・前提合意の解説、言い回し集
- **演習（やってみる・問題数）**: 無理な依頼に前提＋代替案を添えて返す文を5通

#### No.115｜ビジネスマナー（L1）

- **学習目標**: 敬語・電話・オンライン会議・訪問の基本作法を理解し、顧客対応で失礼なく振る舞える
- **学習ステップ**: ①敬語の基本(尊敬/謙譲/丁寧) → ②ビジネス電話の受け答え → ③オンライン会議の作法(入退室/画面共有/カメラ) → ④訪問・名刺・席次の基本 → ⑤NG例から学ぶ
- **教材（読む／見る）**: ビジネスマナーの解説、良い/悪い対応の例
- **演習（やってみる・問題数）**: 敬語の言い換え15問／模擬電話・模擬オンライン会議の受け答え各2回／NG対応の指摘5題
- **備考**: 【追加】漏れ点検

### アウトプット（資料・文章・プレゼン）

#### No.17｜議事録（L1）

- **学習目標**: 決定事項/宿題/論点に分け、事実と解釈を分けて正確に残せる
- **学習ステップ**: ①議事録の型(決定/TODO/論点/保留) → ②良い議事録を読む → ③メモから議事録化 → ④事実と解釈の分離を点検 → ⑤宛先に合わせて要約
- **教材（読む／見る）**: 議事録のテンプレ・良い例
- **演習（やってみる・問題数）**: 模擬会議のメモから議事録を3本作成

#### No.18｜資料作成（スライド）（L1）

- **学習目標**: 1スライド1メッセージ・結論先出しで、伝わるスライドを作れる
- **学習ステップ**: ①スライドの型(メッセージ→根拠) → ②良い/悪い比較 → ③メッセージから1枚作る → ④図解/レイアウトの基本 → ⑤通しのストーリー
- **教材（読む／見る）**: スライド作成の解説、良いスライド例
- **演習（やってみる・問題数）**: 主張を1スライド1メッセージで5枚／3枚構成の短い資料を1本

#### No.19｜文章作成（L1）

- **学習目標**: 簡潔で誤解のないビジネス文(メール/チャット)を書ける
- **学習ステップ**: ①メール/チャットの型 → ②件名/結論先出し → ③依頼/お礼/お詫び/相談の型 → ④推敲(冗長/曖昧を削る)
- **教材（読む／見る）**: ビジネス文/メールの型と例
- **演習（やってみる・問題数）**: 依頼・お礼・お詫び・相談・催促のメールを各1通(計5通)書き推敲

#### No.20｜プレゼン（L1）

- **学習目標**: 相手の理解度に合わせて構成し、伝え直せる
- **学習ステップ**: ①話の構成(結論→根拠→具体) → ②相手に合わせる(専門/非専門) → ③話し方/間 → ④想定問答 → ⑤模擬プレゼン
- **教材（読む／見る）**: プレゼン構成の解説、プレゼン動画
- **演習（やってみる・問題数）**: 同じ内容を専門家向け/初心者向けに2通り＋想定問答を作る

#### No.117｜スプレッドシート・データ集計（L1）

- **学習目標**: 表計算ソフトで集計・基本関数・グラフ化ができ、表形式の成果物を作れる
- **学習ステップ**: ①表の基本操作と整形 → ②基本関数(SUM/IF/COUNTIF/VLOOKUP等) → ③並べ替え・フィルタ・ピボット → ④グラフ化 → ⑤伝わる表に整える
- **教材（読む／見る）**: スプレッドシート入門、集計用サンプルデータ
- **演習（やってみる・問題数）**: 集計課題10問／生データから集計表＋グラフの成果物を2本
- **備考**: 【追加】漏れ点検

#### No.118｜業務でのAI活用（リサーチ・文書作成）（L1）

- **学習目標**: 調査・議事録・メール・資料のたたき台作成にAIを活用し、出力を検証して仕上げられる
- **学習ステップ**: ①業務別のAI活用パターンを知る → ②調査での使い方(出典確認込み) → ③議事録・メールのたたき台生成 → ④資料構成の壁打ち → ⑤出力の検証と仕上げ
- **教材（読む／見る）**: 業務でのAI活用事例、プロンプトの型
- **演習（やってみる・問題数）**: 会議メモから議事録をAIで作成し検証2本／調査タスクをAI＋一次情報で1本／メール下書きと推敲5通
- **備考**: 【追加】漏れ点検

- **学習ステップ**: ①ゴール/スコープ → ②WBS(作業分解) → ③スケジュール/担当 → ④進捗管理 → ⑤課題・リスク管理

#### No.22｜タスク・論点の管理（L1）

- **学習ステップ**: ①論点管理表(オープン/クローズ) → ②優先度付け → ③更新の習慣 → ④報告への接続
- **教材（読む／見る）**: 論点/課題管理表のサンプル
- **演習（やってみる・問題数）**: 進行中タスクの論点管理表を作り1週間毎日更新

#### No.23｜工数見積（L2）

- **学習ステップ**: ①見積りの考え方(分解/類推/三点) → ②機能を分解 → ③各々を見積もる → ④バッファ/前提を明示 → ⑤実績と比べて補正
- **教材（読む／見る）**: 工数見積の解説、見積り表の例
- **演習（やってみる・問題数）**: 機能を分解して見積もる2案件／前提と根拠を添える

#### No.24｜素早いたたき台（L1）

- **学習ステップ**: ①「まず60点」の意義 → ②全体を粗く埋める → ③早くレビューに出す → ④フィードバックで磨く
- **教材（読む／見る）**: 素早い初稿/プロトタイピングの考え方
- **演習（やってみる・問題数）**: 制限時間(例30分)で課題の初稿を出す3回

#### No.116｜報連相・進捗報告（L1）

- **学習ステップ**: ①報連相の違いと使い分け → ②報告の型(結論→状況→相談事項) → ③定期報告(日次/週次)の書き方 → ④悪い知らせ・遅延の伝え方 → ⑤相談の仕方(選択肢を添えて聞く)
